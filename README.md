# MineFix Website

Dit is de complete broncode voor de MineFix Minecraft server website.

## Functies
- **Home & Whitelist-systeem:** Spelers kunnen hun Minecraft-naam opgeven om toegang te vragen.
- **Winkel (Shop):** Toont ranks en serverpakketten.
- **Admin Paneel:** Beheer whitelist tickets en voeg shopitems toe of verwijder ze.

## Inloggegevens Admin Paneel
- **Wachtwoord:** `MinefixAdmin2026`

## Uploaden naar GitHub Pages
1. Pak dit ZIP-bestand uit.
2. Upload het bestand `index.html` rechtstreeks in de hoofdmap (root) van je `minefix` repository op GitHub.
3. Zorg dat GitHub Pages aanstaat via **Settings > Pages** op GitHub.
